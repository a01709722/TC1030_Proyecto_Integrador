# TC1030_Proyecto_Integrador 
Este proyecto es un sistema de gestión hospitalaria desarrollado con C++ como proyecto final de la materia Programación Orientada a Objetos (POO). El sistema simula la administración básica de un hospital, permitiendo gestionar pacientes, doctores, enfermeros y la ocupación de cuartos distribuidos en pisos. El diseño aplica una clase abstracta, herencia, polimorfismo virtual en tiempo de ejecución, sobreescritura, sobrecarga de métodos y modificadores de acceso. 
# Funcionalidad 
El sistema opera a través de un menú de consola interactivo desde el cual el usuario puede realizar las siguientes acciones. Es posible agregar un paciente al hospital ingresando su nombre, edad, diagnóstico y fecha de ingreso; el sistema busca automáticamente un cuarto disponible y lo asigna en el primer piso y cuarto libre, y en caso de no haber cuartos disponibles lo notifica sin realizar la admisión. También se puede consultar la lista de pacientes internados organizada por piso y cuarto, mostrando ID, nombre y diagnóstico de cada uno, lo que permite al usuario identificar el ID necesario para liberar a un paciente. Además es posible buscar a un paciente específico ya sea por su ID o por su nombre, según el dato con el que cuente el usuario. Al liberar un paciente mediante su ID, el cuarto vuelve a quedar disponible. 

En cuanto al personal del hospital, el sistema permite agergar doctores con su nombre, edad, especialidad, cédula y precio de consulta, así como enfermeros con sus datos correspondientes. Como todos los miembros del personal comparten la clase base abstracta PersonalHospital, se almacena y se recorren dentro de una misma colección de tipo PersonalHospital*. Al recorrer esa colección, el código es el mismo para todos los elementos, pero gracias al polimorfismo cada objeto responde a su propia versión de mostrarInfo() según su tipo real, ya sea doctor o enfermero. Cualquier miembro del personal puede darse de baja indicando únicamente su cédula, sin necesidad de especificar si se trata de un doctor o de un enfermero: como la cédula es un dato común a todo el personal, el sistema recorre la colección, encuentra al miembro correspondiente y lo elimina sin importar su tipo. El sistema también puede mostrar la lista completa del personal, presentándola agrupada en dos secciones, una para los doctores y otra para los enfermeros, de modo que la información de ambos tipos no aparezca mezclada. Por último, se puede consultar el estado de ocupación general del hospital indicando cuántos cuartos están ocupados y cuántos disponibles por piso.
