# TC1030_Proyecto_Integrador 
Este proyecto es un sistema de gestión hospitalaria desarrollado con C++ como proyecto final de la materia Programación Orientada a Objetos (POO). El sistema simula la administración básica de un hospital, permitiendo gestionar pacientes, doctores, enfermeros y la ocupación de cuartos distribuidos en pisos. El diseño aplica una clase abstracta, herencia, polimorfismo virtual en tiempo de ejecución, sobreescritura, sobrecarga de métodos y modificadores de acceso. 
# Funcionalidad 
El sistema opera a través de un menú de consola interactivo desde el cual el usuario puede realizar las siguientes acciones. Es posible agregar un paciente al hospital ingresando su nombre, edad, diagnóstico y fecha de ingreso; el sistema busca automáticamente un cuarto disponible y lo asigna en el primer piso y cuarto libre, y en caso de no haber cuartos disponibles lo notifica sin realizar la admisión. También se puede consultar la lista de pacientes internados organizada por piso y cuarto, mostrando ID, nombre y diagnóstico de cada uno, lo que permite al usuario identificar el ID necesario para liberar a un paciente. Además es posible buscar a un paciente específico ya sea por su ID o por su nombre, según el dato con el que cuente el usuario. Al liberar un paciente mediante su ID, el cuarto vuelve a quedar disponible. En cuanto al personal del hospital, el sistema permite agergar doctores con su nombre, edad, especialidad, cédula y precio de consulta, así como enfermeros con sus datos correspondientes. Como todos los miembros del personal comparten la clase base abstracta PersonalHospital, se almacena y se recorren dentro de una misma colección de tipo PersonalHospital*. Al recorrer esa colección, el código es el mismo para todos los elementos, pero gracias al polimorfismo cada objeto responde a su propia versión de mostrarInfo() según su tipo real, ya sea doctor o enfermero. Cualquier miembro del personal puede darse de baja indicando únicamente su cédula, sin necesidad de especificar si se trata de un doctor o de un enfermero: como la cédula es un dato común a todo el personal, el sistema recorre la colección, encuentra al miembro correspondiente y lo elimina sin importar su tipo. El sistema también puede mostrar la lista completa del personal, presentándola agrupada en dos secciones, una para los doctores y otra para los enfermeros, de modo que la información de ambos tipos no aparezca mezclada. Por último, se puede consultar el estado de ocupación general del hospital indicando cuántos cuartos están ocupados y cuántos disponibles por piso. 
# Casos en los que no funciona 
El sistema no contempla la persistencia de datos, por lo que toda la información se pierde al cerrar el programa, ya que no se contacta ninguna base de datos ni se generan archivos. No es posible agergar pisos ni cuartos en tiempo de ejecución, ya que la estructura del hospital se define al momento de inicializar el programa y no cambia. El sistema tampoco valida duplicados, por lo que es posible registrar dos miembros del personal con la misma cédula o dos pacientes con los mismo datos sin que el programa lo detecte. La asignación de cuartos es automática y no permite elegir un piso o cuarto específico para un paciente. Tampoco es posible editar la información de un paciente o de un miembro del personal una vez registrado; para corregir datos habría que eliminar el registro y volver a ingresarlo. 
# Casos en los que crashea
- Si en un campo que espera un número se ingresa una letra u otro caractér no válido, el flujo de entrada entra en estado de error. Esto provoca que las lecturas siguientes se omitan y el programa puede quedar en un bucle o terminar de forma inesperada, ya que no se limpia ni valida la entrada.
  
- Si se selecciona una opción que no está dentro de las disponibles en el menú, el programa finaliza la ejecución y saca al usuario del programa.  
# Cómo compilar y ejecutar 
El proyecto se complia con cualquier compilador de C++. Desde la carpeta del proyecto, ejecuta g++ main.cpp -o hospital para generar el ejecutable a partir de todos los archivos fuente. Luego corre el programa con ./hospital en Linux o macOs, o hospital.exe en Windows.
