# TC1030_Proyecto_Integrador
Este proyecto es un sistema de gestión hospitalaria desarrollado en C++ como proyecto final de la materia de Programación Orientada a Objetos (POO). El sistema simula la administración básica de un hospital, permitiendo gestionar pacientes, doctores y la ocupación de cuartos distribuidos en pisos. El diseño aplica clases abstractas, herencia, polimorfismo virtual en tiempo de ejecución, sobreescritura, sobrecarga de métodos y modificadores de acceso. 
# Funcionalidad 
El sistema opera a través de un menú de consola interactivo desde el cual el usuario puede realizar las siguientes acciones. Es posible agregar un paciente al hospital ingresando su nombre, edad, diagnóstico y fecha de ingreso; el sistema busca automáticamente un cuarto disponible y lo asigna en el primer piso y cuarto libre disponible, o en caso de no haber espacio, agrega al paciente a una lista de espera. También se puede consultar la lista de pacientes internados organizada por piso y cuarto, mostrando ID, nombre y diagnóstico de cada uno, lo que permite al usuario identificar el ID necesario para liberar a un paciente. Al liberar un paciente mediante su ID, el cuarto queda disponible y si hay pacientes en la lista de espera, el siguiente es asignado automáticamente a ese cuarto. En cuanto a los doctores, el sistema permite agergar un doctor con su nombre, edad, especialidad, cédula y precio de consulta, así como eliminarlo usando su cédula. El sistema puede mostrar la lista completa de doctores con toda su información incluyendo especialidad, cédula y precio de consulta o filtrar esa lista por especialidad mostrando únicamente nombre y especialidad. Por último, se puede consultar el estado de ocupación general del hospital indicando cuántos cuartos están ocupados y cuántos disponibles por piso.
