# TC1030_Proyecto_Integrador
Este proyecto es un sistema de gestión hospitalaria desarrollado en C++ como proyecto final de la materia de Programación Orientada a Objetos (POO). El sistema simula la administración básica de un hospital, permitiendo gestionar pacientes, personal hospitalario (doctores y enfermeros) y la ocupación de cuartos distribuidos en pisos. El diseño aplica clases abstractas, herencia, polimorfismo virtual en tiempo de ejecución, sobreescritura, sobrecarga de métodos y modificadores de acceso. 
# Funcionalidad 
El sistema opera a través de un menú de consola interactivo desde el cual el usuario puede realizar las siguientes acciones. Es posible agregar un paciente al hospital ingresando su nombre, edad, diagnóstico y fecha de ingreso; el sistema busca automáticamente el primer cuarto disponible y lo asigna. También se puede consultar la lista de pacientes internados organizada por piso y cuarto, mostrando ID, nombre y diagnóstico de cada uno, lo que permite al usuario identificar el ID necesario para liberar a un paciente. Al liberar un paciente mediante su ID, el cuarto queda disponible nuevamente. En cuanto al personal del hospital, el sistema permite agregar doctores y enfermeros. Al agregar personal, el usuario decide si es doctor o enfermero e ingresa los datos correspondientes. Para los doctores se registra nombre, edad, especialidad, cédula, y precio de consulta; para los enfermeros se registra nombre, edad y turno. El sistema también permite eliminar personal, donde el ususario indica si desea eliminar un doctor o un enfermero y proporciona el identificador correspondiente. Se puede mostrar la lista completa del personal o filtrarla por tipo, mostrando únicamente doctores o únicamente enfermeros. Además el sistema puede ejecutar las tareas propias de cada miembro del personal, donde cada uno realiza la función correspondiente a su rol. Por último, se puede consultar el estado de ocupación general del hospital indicando cuántos cuartos están ocupados y cuántos disponibles por piso. 
# Diseño
La clase PersonalHospital es abstracta y no puede instanciarse directamente: solo existen objetos tipo Doctor o Enfermero. El polimorfismo virtual en tiempo de ejecución se aplica a través del método virtual trabajo(), declarado en PersonalHospital y sobreescrito en Doctor y Enfermero, cada uno con un comportamiento distinto según su rol. Esto permite que al llamar trabajo() sobre un puntero PersonalHospital*, se ejecuté la versión correcta en tiempo de ejecución. La sobrecarga se aplica en el método mostrarPersonal() de la clase Hospital: sin parámetros muestra a todo el personal, mientras que al recibir un string con el tipo filtra la lista mostrando únicamente doctores o únicamente enfermeros. La variable tipo en PersonalHospital se utiliza para que eliminarPersonal() sepa cómo identificar al empleado: si es doctor lo busca por cédula, si es enfermero lo busca por nombre. La estructura del hospital se inicializa con un número fijo de pisos y cuartos por piso definido al momento de crear el objeto Hospital en el código, y no cambia en tiempo de ejecución.
# Casos en los que no funciona
EL programa crashea si el usuario ingresa una letra o un carácter no numérico cuando el programa solicita un número, el flujo de entrada queda en un estado inválido y el programa puede comportarse de forma impredecible o terminar abruptamente. Si el usuario ingresa una opción que no existe en el menú, el programa termina. El sistema no contempla persistencia de datos, por lo que toda la información se pierde al cerrar el programa. No es posible agregar ni pisos ni cuartos en tiempo de ejecución. El sistema no valida duplicados, por lo que es posible registrar dos doctores con la misma cédula o dos pacientes con los mismos datos sin que el programa lo detecte. La asignación de cuartos es automática y no permite elegir piso o cuarto específico. No es posible editar la información de un paciente o miembro del personal una vez registrado: para corregir datos habría que elkiminar el registro y volver a ingresarlo. 
# Cómo Compilarlo 
Desde la terminal, navega a la carpeta del proyecto y ejecuta:
g++ -o hospital main.cpp
Luego corre el programa con: 
./hospital
